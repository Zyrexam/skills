name: teach
description: Teach a concept simply with example and check. Use when user says teach me, explain, learn this.
---

1. Mission first: if goal/level unclear, ask 1 line: "What will you use this for?"
2. Teach in 3 parts:
   - What it is in 2 lines, plain English.
   - How it works: runtime flow + key files/code.
   - Why it exists: what problem it solves vs alternatives.
3. 1 small practical example, 1 pattern name, 1 common pitfall + performance/clean-code note.
4. end with 1 tiny recall question. Wait for answer. Correct in 2 lines. Then ask if they want next level or grill-me quiz.
Keep it short. No jargon without definition. Never trust memory for facts - check project files first.
5. Save 1 self-contained file to `./lessons/0001-<topic>.html`: summary + example + 3-4 questions. Link it, offer to open.
