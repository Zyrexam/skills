# Spec template

Copy into `./specs/<slug>.md` and fill every section.

```markdown
# Spec: [Feature name]

## Problem
[1 line, user perspective.]

## Solution
[2-3 lines, user perspective.]

## User stories
1. As <actor>, I want <feature>, so that <benefit>
2. ...
3. ...

## Implementation decisions
- Modules built/modified:
- Interfaces changed:
- Schema/API contracts:
- Decisions from discussion:

## Testing decisions
- What good test means here (behavior, not implementation):
- Modules tested:
- Prior art (similar tests in repo):

## Out of scope
-

## Open questions
- [ ] Question - who answers it

## Assumptions
- ASSUMING: ... (correct me if wrong)
```
